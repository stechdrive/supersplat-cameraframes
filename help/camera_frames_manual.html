CAMERA FRAMES 操作マニュアル

CAMERA FRAMES は、A4相当の基準用紙の上に複数の撮影フレームをレイアウトし、構図（カメラの位置・向き・画角）を調整して、LO用紙テンプレとぴったり合う画像を書き出すためのツールです。Webブラウザで動作します。本マニュアルは CAMERA FRAMES v2.18.0 に対応しています。
URL: https://stechdrive.github.io/supersplat-cameraframes/

CAMERA FRAMES on Supersplat を開く

はじめに（基本の流れ）

  • 3Dデータ（.ply/.splat/.sog/.lcc など）や 3Dモデル（.glb）を読み込みます。
  • 大判指定で基準用紙のサイズ（幅/高さ）と基準点を決めます。
  • フレーム一覧で撮影フレームを追加し、ビューポート上で位置・回転・拡縮を調整します。
  • 撮影カメラ表示（ON）で構図を仕上げ、編集カメラ表示（OFF）で別視点を確認します。編集視点で撮影カメラを調整したい場合は撮影カメラ操作パネルを開きます。
  • 書き出しで PSD/PNG をレンダリングして書き出します。

0. ファイルの読み込み

ブラウザへドラッグ・アンド・ドロップすると読み込みできます（複数ファイル可）。画像ファイル（.png / .jpg / .jpeg / .webp / .psd）のみをドロップした場合は、下絵（参考画像）として読み込まれます（複数可）。

読み込めるもの 拡張子例 用途
ロケ地などの3Dデータ .ply / .splat / .sog / .lcc 背景などのベースとして配置します（複数読み込み可）。
3Dモデル .glb 小物やキャラなどの当たりを置いて構図確認に使います。
シーンファイル .ssproj カメラや撮影フレーム、マスク、下絵などを含めて再現できます。
下絵（画像） .png / .jpg / .jpeg / .webp / .psd 基準用紙に重ねて表示し、位置合わせのガイドにできます（PSD はレイヤーごとに分割して下絵として読み込み）。

1. UIパネルからの操作（設定・書き出し）

操作の中心は、画面右側の カメラフレーム パネルです。パネル内の一部項目は▶/▼で折りたためます。 撮影カメラ表示の見え方が、最終的にレンダリングされて出力されます。

1-0. パネルヘッダー（撮影/編集・下絵・コンパクト）

項目 主な機能 ポイント
撮影/編集カメラ切り替え 表示モードの切替（ON=撮影／OFF=編集）
  • 撮影カメラ表示（ON）は CAMERA FRAMES を有効にして構図を決めるモードです。
  • 編集カメラ表示（OFF）は自由に移動して確認するためのモードです。
  • 書き出しは撮影カメラ表示の構図で行われます。
撮影カメラ操作 撮影カメラ操作パネル
  • 編集カメラ表示中に撮影カメラ操作パネルを開き、撮影カメラのレンズ/位置/回転/ニアクリップを調整できます。
  • 撮影カメラ表示中はロックされて開けません。
下絵 下絵パネルの表示
  • パネルヘッダーの下絵アイコンで、下絵パネルを開きます。
  • その隣の目アイコンで、下絵（全体）の表示/非表示を切り替えます（下絵があるときのみ有効）。
ヘルプ ヘルプパネルの表示
  • パネルヘッダーの？アイコンで、ヘルプパネルを開きます。
  • 現在開いているヘルプパネルの開閉ができます。
コンパクト切替 パネルの折りたたみ
  • パネルをヘッダーだけの表示にして作業スペースを広げられます。
  • パネルヘッダーはドラッグで移動できます（ウィンドウ内に収まるように自動調整）。

1-1. 大判指定（基準用紙のサイズ）

  • 基準点: 3×3アンカーで拡縮の基準を指定します。
  • 幅/高さ(%): A4基準用紙（1754×1240px @150dpi）に対する拡大率です（最小100%、UIは1000%まで／内部は16000px上限）。
  • 表示倍率: 25..100%。プレビュー表示のみ縮小され、書き出しサイズには影響しません。
  • 出力解像度: 実際に画像として出力される縦横のピクセル数です。

1-2. 書き出し（PSD/PNG書き出し）

  • 書き出し: PSD/PNG形式を選びます。
  • グリッド/アイレベル: グリッドとアイレベルを出力画像に含めます（PNGは合成、PSDは個別レイヤー）。
  • モデルレイヤー: PSD時のみ有効。GLBモデルをモデル単位でレイヤー出力します（シーンが重い場合は時間がかかります）。
  • 下絵（出力）: 出力対象の下絵があるとアイコンが有効/点灯します。クリックで下絵パネルを開き、各下絵の出力を切り替えます（PSDはレイヤー、PNGは合成）。
  • 書き出し詳細: ファイル名を編集できます。空欄の場合はデフォルトでcf-%camが使われ、%camはカメラ名に置換されます（例: デフォルトのカメラ名がcamera1ならcf-%cam→cf-camera1）。
  • 書き出し対象: 現在のカメラ/全カメラ/選択カメラを切り替えます。選択カメラ時はカメラリスト内にチェックが表示され、対象を選べます。
  • レンダリング: 現在の構図でファイルに画像を出力します。

カメラリスト は、撮影カメラの構図と Camera Frames の設定（大判指定・撮影フレーム・ニアクリップ等）をプリセットとして管理する機能です。リストをクリックして切り替え、内容は.ssprojに保存されます。.sscamはリスト全体を一括で書き出し/読み込みします。

  • 追加: ヘッダーの追加アイコンで、現在の構図をリストに保存します。
  • 削除: ヘッダーの削除アイコンで、選択中プリセットを削除します。
  • 適用: リスト項目をクリックすると即座に構図が切り替わります。
  • 名前編集: 項目名をダブルクリックで編集します（Enter/フォーカス外で確定、Escでキャンセル）。
  • 下絵（Reference Image）: 各カメラに紐づく下絵セットを行内のセレクトで切り替えます。カメラ追加時は共通の(blank)にリンクされ、下絵を初めて読み込むと読み込んだ最初のファイル名で新規セットが作成されて自動で切り替わります。
  • 書き出し（.sscam）: ヘッダーのエクスポートアイコンで、カメラリストをファイルに保存します。
  • 読み込み（.sscam）: ヘッダーのインポートアイコンで、カメラリストを読み込み、現在のリストを置き換えます（必要ならUndoで戻せます）。
  • 注意: .sscamには、読み込んでいるロケ地データ（.ply/.splat/.sog/.lcc など）や3Dモデル（.glb）は保存されません。アセットの差し替え・移動/回転/スケールなどを行うと、同じカメラでも画が合わない場合があります。構図を固定したい場合は、アセット側を変えないか、編集後に再度書き出ししてください（シーン全体の保存は.ssprojを利用します）。

1-3. 撮影フレーム（フレーム一覧）

  • フレーム追加/フレーム削除: 新しい撮影フレームを追加（最大20個）/削除します。
  • リスト: クリックで選択・再クリックで解除します。リストには実効ピクセルサイズの目安も表示されます。
  • フレーム拡縮(%): 選択中フレームのスケールを数値指定します（10..400%にクランプ）。

1-4. マスク（フレーム外を暗く表示）

  • マスク: ONでフレーム外を暗く表示します（プレビュー専用で、PNG/PSDには含まれません）。
  • マスク詳細: 範囲（全体/選択）と不透明度を調整できます。範囲が「選択」のとき、選択フレームがない場合は全体扱いになります。

1-5. 撮影/編集カメラ操作（カメラの移動・回転・画角）

  • FPV/オービット: マウスでのカメラ操作方式を切り替えます（詳細は「2. マウス・ビューポート操作」参照）。
  • 撮影カメラ(mm): 撮影カメラ表示時のみ。撮影カメラの画角（35mm判換算）を調整し、書き出しの構図に影響します。
  • 編集カメラ(mm): 編集カメラ表示時のみ。編集視点の画角（35mm判換算）を調整します。
  • 撮影カメラ操作パネル: 編集カメラ表示中に、撮影カメラのレンズ/位置/回転/ロール固定/ローカル移動/ニアクリップを調整します。
  • X, Y, Z / Yaw, Pitch, Roll: 表示中のカメラ（撮影表示=撮影カメラ／編集表示=編集カメラ）の位置と回転を精密に調整します。ロール固定も可能です。
  • 左右・上下・前後: スライダーでローカル方向へ移動します（Altキーで微調整）。
  • ニアクリップ: カメラに近い邪魔なものを写さないための表示カット距離（m）です。編集カメラ表示中は撮影カメラ操作パネル側で調整します。

1-6. 下絵（参考画像）

下絵は、基準用紙に重ねて表示できるガイド画像です。LOテンプレやレイアウトのガイド画像を読み込み、カメラやフレームの位置合わせに使えます。カメラごとに下絵セットを切り替えられ、カメラリストのセレクトからリンク先を変更できます。複数登録でき、PSD を読み込むとレイヤーごとに下絵として展開されます。

  • 下絵パネルを開く: カメラフレームパネルのヘッダーにある下絵アイコンをクリックします（書き出し欄の下絵アイコンからも開けます）。
  • 読み込み（複数可）: 下絵パネルの＋から画像を選択して読み込みます（.png / .jpg / .webp / .psd）。ブラウザへのドラッグ&ドロップでも読み込みできます。
  • PSD読み込み: PSD はレイヤーごとに下絵として追加されます（レイヤー名/不透明度/表示状態を反映。隠しレイヤーは非表示で取り込み）。
  • 登録名: 下絵パネル上部の入力欄で、現在の下絵セット名を編集できます（(blank) は編集不可）。
  • カメラ別調整: 表示/出力/並び順/位置/不透明度/スケールなどの調整は、選択中カメラごとに保存されます。読み込み/削除/登録名の変更は共通の下絵セットを編集し、全カメラに反映されます。
  • 表示: 各行の目アイコンで表示/非表示を切り替えます。ヘッダーの目アイコンで下絵（全体）も一括表示/非表示できます。
  • 前面/背面: 下絵パネル内は前面（3Dの上に重ねる）/ 背面（3Dの後ろに敷く）の2リストに分かれます。
  • 並び順（優先順位）: リストの上側が優先（手前）です。矢印ボタンで順序を変えられます。
  • 選択（複数）: クリックで選択、Ctrl/Cmd+クリックで追加選択、Shift+クリックで同じリスト内の範囲選択ができます。
  • 一括表示/出力: 複数選択中に目アイコンや出力アイコンを押すと、選択中の下絵にまとめて反映されます。
  • 出力: 各行の出力アイコンで、書き出しに含めるかを切り替えます（PSDはレイヤー、PNGは合成）。
  • 初期化: 初期化ボタンが表示されている行はカメラ別で上書きされています。クリックするとそのカメラの調整を解除し、共通の状態に戻します。
  • 調整: 選択した下絵のスケール/不透明度/オフセットを調整します。センタリングで位置を戻せます。
  • 一括移動/調整: 複数選択した状態でオフセットを変更すると、選択した下絵が同じ量だけ移動します。スケールは選択全体の中心を基準に拡縮し、不透明度は一括で変更されます。

1-7. シーンマネージャー（ロケ地データ/3Dモデルの表示・移動）

既存のPLY/SOG/LCCなどのロケ地データや、読み込んだGLBモデルはシーンマネージャーで管理できます。表示の切り替えや、位置・回転・拡縮の調整を行いたい場合は次の手順で操作します。

  • メニューを展開: 画面左上の「＞」をクリックして折りたたみを解除します（シーンマネージャーと画面下部のツールバーが表示されます）。
  • オブジェクトを選択: シーンマネージャーの一覧から、操作したいロケ地データ（.ply/.splat/.sog/.lcc など）や3Dモデル（.glb）の名前をクリックします。
  • 複数選択: Ctrl/Cmd+クリックで追加/解除、Shift+クリックで同じリスト内の範囲選択ができます。最後にクリックした項目がアクティブになります。
  • 表示/非表示: 一覧の目アイコンをクリックして切り替えます。
  • 移動/回転/スケール: 画面下部のツールバーから移動 ( 1 ) / 回転 ( 2 ) / スケール ( 3 )を選び、表示されるギズモをドラッグします。
  • 複数選択の編集: 複数選択時は共通ピボットで移動/回転/スケールします。ローカルではアクティブ項目の向き、ワールドでは世界軸が回転基準です。
  • 数値で微調整: シーンマネージャー内のトランスフォーム（位置/回転/スケール）で数値入力して精密に調整できます。
  • 座標系・基準点: ツールバーのローカル/ワールド切替や中心/バウンディング中心切替で、操作の感覚を合わせられます。
  • ガウス選択ツール: 矩形/ブラシ/ラッソなどの部分選択は、単一のロケ地データを選択した状態で使用します（複数選択中は無効）。

2. マウス・ビューポート操作

2-1. 撮影フレーム操作

目的 操作 詳細
選択 撮影フレームをクリック 赤枠が点線になり、ハンドルが表示されます。フレーム一覧から選択と選択解除をすることもできます。
移動 フレーム枠をドラッグ Shift + ドラッグで、垂直・水平方向に移動を制限。
リサイズ 四隅/辺の白いハンドル（□）をドラッグ Alt + ドラッグでフレーム固有アンカーを中心に対称拡縮（10-400%にクランプ）。
回転 上部の回転ハンドル中央上部（□）をドラッグ Shift + ドラッグで、15度刻みでスナップ回転します。
アンカー移動 フレーム上のアンカーポイントをドラッグ 基準点を変更できます。ダブルクリックでフレーム中心に戻します。
リセット 回転ハンドル / アンカーポイントをダブルクリック 回転を0度に、またはアンカーをフレームの中央に戻します。
パン 画面の何もないところでShift+左ドラッグ 用紙全体をブラウザウィンドウの中で移動できます（はみ出しは自動でクランプ）。

2-2. FPVカメラ操作（一人称視点での移動）

FPVモード選択時のカメラ操作です（撮影カメラ/編集カメラどちらでも共通）。

FPVモード：視点移動（左ドラッグ）、前後移動（ホイール）、平行移動（右ドラッグ）
  • 視点移動: 左ドラッグで視線の向きを変更します。
  • 前後移動: マウスホイールで前後に移動します。（Alt + ホイールでゆっくり移動）
  • 平行移動: 右ドラッグで上下左右に移動します。（Alt + 右ドラッグでゆっくり移動）
  • ピボット回転: Ctrl + 左ドラッグで、クリックした地点を中心にカメラを回転させます。（被写体を回り込むのに便利）

2-3. オービットカメラ操作（注視点の周りを回る）

オービットモード選択時のカメラ操作です。

  • 回り込み: 左ドラッグで注視点の周りを回転します。
  • 平行移動: 右ドラッグでカメラを平行移動します。
  • ズーム: ホイール（または中ドラッグ）で前後にズームします。
  • 注視点変更: ダブルクリックでクリックした場所に注視点を移動します。

3. その他・補足

ヒント：現在の状態を保存したい / メニューを開くには
画面左上のアイコンの「＞」をクリックしてメニューを展開してください。そのメニューの「ファイル」 → 「名前を付けて保存」 から、3Dデータやカメラ、撮影フレーム、マスク、下絵などを再現可能なシーン全体を保存できます。
  • Undo/Redo: 撮影フレーム編集・マスク・下絵・カメラ調整などは Ctrl+Z / Ctrl+Shift+Z で戻せます。
  • 自動フィット: ウィンドウサイズ変更などで、レイアウト用紙全体が画面に収まるように自動的に表示倍率が調整されます。
  • プレビュー＝書き出し: プレビューで見えている用紙サイズ内が指定解像度で出力されます。マスクはプレビュー専用でPNG/PSDには含まれません。
  • 更新が反映されない: PWA/サービスワーカーのキャッシュの影響で表示が古い場合があります。Ctrl+Shift+Rでハードリロードするか、ブラウザのサイトデータ（キャッシュ）を削除してください。
  • 複数PLY/SPLAT/GLBの統合レンダリング: 複数の3Dデータを読み込んでも、深度順に統合して描画されるため、ビューポート・書き出しともに正しく遮蔽が効きます。
  • GLB読み込み: シーンパネルのインポートやブラウザへのドラッグ&ドロップでGLBを読み込み、スプラットと並べてレイアウト確認が可能です。GLB形式に変換するにはBlenderでモデルを読み込んで、ファイルメニュー＞エクスポートからglTF2.0という形式を選んで出力してください。
  • ライティング操作: 画面左上の＞ボタンをクリックしてシーンパネルを開きます。照明の項目でライトのON/OFF、ライトの選択、照明と環境光の強さを調整できます。ライトを選択すると、その下のトランスフォーム項目からライトの方向を回転させることができます。ライトはGLBモデル用です。
