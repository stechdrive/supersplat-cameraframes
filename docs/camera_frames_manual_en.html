CAMERA FRAMES Manual

CAMERA FRAMES lets you place multiple camera frames on an A4-like render sheet, manage a capture camera, use reference images, and export matching PNG / PSD output. This is the user manual for CAMERA FRAMES v2.21.13.

URL: https://stechdrive.github.io/supersplat-cameraframes/?lng=en

Open CAMERA FRAMES on SuperSplat

1. Supported Files

Type Examples Use
Project files .ssproj The save/load format for the CAMERA FRAMES working state. It restores the scene, camera frames, reference images, lighting, and the rest of the working state together.
3DGS / splat data .ply / .splat / .sog / .lcc Load these as source assets such as backgrounds, locations, and main 3DGS scene content.
3D models .glb Load these as source assets for props, rough placement, and composition checks.
Reference images .png / .jpg / .jpeg / .webp / .psd Load these as source images for storyboards and alignment. PSD files are split into multiple reference-image items.

2. Basic Workflow

CAMERA FRAMES is meant for deciding one shot, creating the next shot with the same assets, and exporting the whole set at the end. A typical workflow looks like this.

  1. Load 3DGS files (.ply / .sog / .splat / .lcc and similar), 3D model files (.glb), or an existing .ssproj.
  2. When needed, use Scene Manager and Transform to place or adjust the assets. You can also add small GLB props later and adjust them per shot.
  3. For shots that need camera movement, set up the base sheet in Layout when needed, then add the required Frames.
  4. Choose the lens feel with Capture Camera (mm), then move the camera with Capture Camera and Capture Camera Controls until the first shot looks right.
  5. If needed, load Reference Images and align them to a storyboard or rough layout. Reference images can be changed for each camera in Camera List.
  6. Once that shot is decided, add the next camera in Camera List and continue building the next shot with the same assets.
  7. At the end, use Export to write the current camera, all cameras, or selected cameras.

3. Camera Frames Panel

Export, Camera List, Frames, Layout, and Capture Camera Controls are collapsible sections. Click each section header to open or close it.

3-1. Header

  • Toggle Capture/Edit Camera: Switch between Capture Camera and the edit camera. Final export uses the capture-camera view.
  • Capture Camera Controls: Available while the edit camera is active. Lets you edit Capture Camera (mm), transform, near clip, and navigation mode.
  • Reference Images: Open the reference-image panel and toggle global reference-image visibility.
  • Collapse Panel: Collapse the panel to the header only. Use it again to expand the panel.

3-2. Lens

  • Capture Camera (mm) shows the horizontal angle of view inside the red frame when that frame is at 100% size, expressed as a 35mm-film-equivalent lens value. Smaller numbers feel wider; larger numbers feel more telephoto.
  • As a rough guide, 35mm feels slightly wide, around 50mm feels standard, and 85mm or higher feels telephoto.
  • Edit Camera (mm) changes the lens value only for the edit-camera view. Use it when you want a different working view for alignment; it does not change the exported framing.

3-3. Canvas Zoom and Mask

  • Canvas Zoom (%) changes only the preview magnification. It does not change the export result.
  • Mask is preview-only and is not included in PNG or PSD export.
  • All darkens everything outside all frames, while Selected darkens everything outside the selected frame.
  • If no frame is selected, Selected behaves the same as All.
  • Use Opacity to adjust how dark the masked area looks.

3-4. Export

  1. Open Export Details and enter a Filename. The default is cf-%cam. The %cam part is replaced with the camera name at export time, so it is useful when exporting All Cameras or Selected Cameras and you want separate filenames automatically.
  2. Choose PSD or PNG. Use PSD when you want separated layers for later editing, and PNG when you just want the final image.
  3. Choose an Export Target: Current Camera, All Cameras, or Selected Cameras. If you use Selected Cameras, enable the checkmarks in Camera List for the cameras you want.
  4. Use the icons on the right when needed to include Grid / Eye Level or to enable Export GLB Models as Separate Layers. Once Export GLB Models as Separate Layers is on, you can also use Export PLY/SOG Objects as Layers inside Export Details.
  5. Turn on Export PLY/SOG Objects as Layers when you want each PLY / SOG object written as its own PSD layer. This export takes longer.
  6. If you want reference images in the export, enable both Visible and Output for those images in the Reference Images panel. In PSD output, reference images are grouped under Reference Images, and grid / eye level are grouped under Guides.
  7. When everything is ready, switch to Capture Camera and press Render. With All Cameras, every camera in the Camera List is exported in one run.

3-5. Camera List

  • Click a row in Camera List to switch to that camera.
  • Use Add Camera to create a new shot and Delete Camera to remove the current one.
  • To rename a camera, double-click its name in the list and type the new name.
  • Use Export Cameras / Import Cameras to exchange the camera list as a .sscam file.
  • If you want a different reference-image setup for a specific camera, choose it from the reference-image preset field in that row.

3-6. Frames

  • Frames are the red shot rectangles on the sheet. You can place up to 20. Use Add Frame to create one and Delete Frame to remove the selected frame.
  • You can select a frame by clicking it in the list or by clicking the red rectangle directly.
  • Drag inside the red rectangle to move it, drag the edge or corner handles to resize it, drag the rotate handle to rotate it, and drag the anchor handle to change its reference point.
  • Hold Shift while editing for axis lock and 15-degree rotation snap. Hold Alt while resizing to scale symmetrically around the anchor.
  • Hold Shift and drag empty space to move the whole sheet. Double-click the anchor handle to return it to the center, and double-click the rotate handle to reset rotation to 0 degrees.
  • If CAMERA FRAMES is enabled with no frames yet, one default frame is created automatically.

3-7. Layout

  • Base sheet size is 1754 × 1240 px.
  • Width / Height (%) starts at 100% and is clamped so each output dimension stays within 16000px.
  • The 3×3 anchor defines which side of the composition stays fixed during scaling.
  • Output Resolution shows the image size that will be exported with the current settings, so you can adjust sheet size and frame scale while watching the final resolution.

3-8. Capture Camera Controls

  • You can edit position XYZ, yaw / pitch / roll, and near clip numerically in both the main panel and Capture Camera Controls.
  • Hold Alt while editing Position XYZ, Yaw / Pitch / Roll, right / up / forward, or Near Clip when you want finer adjustments.
  • Capture Camera (mm) controls how wide or narrow the framing feels. Smaller values show a wider view, while larger values feel more tightly framed.
  • Local motion sliders nudge the capture camera in right / up / forward directions.
  • Near Clip sets the distance in front of the camera that will not be shown. The unit is meters.
  • Increase it when you want to hide foreground objects very close to the camera and frame the shot from a little farther back. Lower it when you want nearby objects to stay visible.
  • Roll lock keeps the current roll while yaw / pitch changes are applied.

4. Reference Images

  • To use reference images, open the Reference Images panel from the Reference Images button in the header of the Camera Frames panel, then load an image with Load / Replace. Use Clear All when you want to remove everything.
  • Preset Name is the name of the current reference-image setup. If you want different reference-image setups per shot, select a camera in Camera List before adjusting the images.
  • Loaded images are listed under Back or Front. Use the arrow buttons to change their stacking order.
  • Each image has controls for Visible, Output, and Delete.
  • Use Placement, Offset, Centering, Scale, and Opacity to line the image up with the scene.
  • If you want an image to appear in the export, enable both Visible and Output.
  • Use Reset to default to return camera-specific adjustments to the shared preset state.

5. Scene Manager / Transform / Lighting

To open Scene Manager, first click the top-left > button to expand the menu.

When you want to move a 3DGS object or a GLB model, first select it in Scene Manager. Then use Transform to edit Position, Rotation, and Scale numerically.

Use the up/down buttons in the list to change the order of 3DGS and GLB items. When you export object layers to PSD, that order is used as the stacking order.

You can also use the editing tools shown at the bottom of the screen for move, rotate, and scale. Use those tools when you want direct drag-based editing, and use Transform when you want exact numeric values.

When you want to adjust the light, use Lighting. If you want to change the light direction, first press Select Light to select the light. There you can use Toggle Light, Reset Light Direction, Light Intensity, and Ambient.

6. Capture Camera / Edit Camera and Navigation

CAMERA FRAMES has two camera views: Capture Camera for checking what will be exported, and Edit Camera for moving through the scene and adjusting placement. Switch between them with Toggle Capture/Edit Camera in the header.

To change how the camera moves, switch to Edit Camera, then open Capture Camera Controls inside the Camera Frames panel. The icons on the right side of the Capture Camera Controls section header switch between FPV navigation and Orbit navigation.

6-1. FPV Navigation

  • Use this when you want to move the camera more like a person walking through the scene.
  • Left-drag looks around. Drag right to look right, drag left to look left.
  • Right-drag moves the camera left / right / up / down.
  • Mouse wheel moves forward and backward.
  • Hold Ctrl and left-drag to orbit around the pointed location.

6-2. Orbit Navigation

  • Use this when you want to move around the subject while keeping it in view.
  • Left-drag rotates around the subject.
  • Right-drag pans the view left / right / up / down.
  • Mouse wheel moves closer or farther away.
  • Double-click helps center the view around the clicked area.

6-3. Parallel View in Edit Camera

  • When you need accurate alignment from the front, side, or top, use the parallel view in Edit Camera. It reduces perspective depth cues, so matching positions is easier.
  • Use the XYZ gizmo in the top-right corner. Click the X, Y, or Z circle to align the view to that axis and switch to parallel view.
  • When you want normal perspective again, rotate in orbit mode or switch to FPV navigation.

7. Undo / Redo

Numeric edits and layout changes can be undone with Ctrl+Z and redone with Ctrl+Shift+Z.

8. Save Formats

Format Use
.ssproj Project file format for saving the entire scene, CAMERA FRAMES settings, reference images, lighting, and export settings together. Use this when you want to save everything together and reopen the same state later, or when you want to hand the whole setup to another user or environment.
.sscam Camera-list exchange format. It stores camera settings and reference-image preset names, but it does not include scene assets or the actual reference-image files. Use this when you only want to pass camera data.
When to use .ssproj saves
In CAMERA FRAMES, the standard menu is collapsed by default, so first click the top-left > button to open the menu, then go to File.
Regular Save is the fast save used to continue working in the current browser.
When you want to save everything together and reopen the same state later, or before handing the project to another user or opening it in another environment, use File > Save Project Package to update the .ssproj file.
The * mark means you still have unsaved changes. PKG means the .ssproj file is not up to date.
If PKG is shown, use File > Save Project Package before sharing or handoff.
