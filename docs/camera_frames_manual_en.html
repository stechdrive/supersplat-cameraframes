CAMERA FRAMES Manual

CAMERA FRAMES is a layout-oriented fork of SuperSplat for Japanese animation workflows. It lets you place multiple camera frames on an A4-like render sheet, adjust the capture camera, and export PNG / PSD layouts that match the preview.
This manual is for CAMERA FRAMES v2.21.4.
URL: https://stechdrive.github.io/supersplat-cameraframes/?lng=en

Open CAMERA FRAMES on SuperSplat

Getting Started

  • Load 3D splat data such as .ply / .splat / .sog / .lcc or a 3D model such as .glb.
  • Use the Render Box controls to define paper size, scale, anchor, and zoom.
  • Add one or more Camera Frames and edit their position, rotation, scale, and anchor in the viewport.
  • Use CAMERA FRAMES ON to frame the final capture view. Use OFF to explore with the edit camera.
  • Export the shot as PNG or PSD.

What You Can Load

Asset Type Examples Use
Splat data .ply / .splat / .sog / .lcc Use for backgrounds, locations, and other 3DGS scene elements.
3D models .glb Use for props, rough character placement, and composition checks.
Scene files .ssproj Restore saved camera, frame, mask, and reference-image state.
Reference images .png / .jpg / .jpeg / .webp / .psd Use as guide images layered on the render sheet.

Main Panel Overview

  • Header: Toggle CAMERA FRAMES ON/OFF, open the help panel, or open the capture camera controls.
  • Render Box: Set width, height, anchor, and canvas zoom for the sheet.
  • Frames: Add and manage multiple shot frames on one sheet.
  • Mask: Darken the area outside the selected or all frames in preview.
  • Export: Render PNG / PSD, optional overlays, and per-model layers.

Capture View and Edit View

Mode Purpose
CAMERA FRAMES ON Shows the capture composition used for final framing and export.
CAMERA FRAMES OFF Lets you inspect the scene freely with the edit camera.
Capture Camera Controls Edit the capture camera while CAMERA FRAMES is OFF.
Tip: Use ON when you want to judge the final shot, and OFF when you want to inspect the scene or adjust from another angle.

Viewport Operations

  • Select a frame: Click a frame outline or select it in the list.
  • Move a frame: Drag inside the selected frame.
  • Scale a frame: Drag an edge or corner handle. Hold Alt for symmetric scaling around the anchor.
  • Rotate a frame: Drag the rotation handle above the frame. Hold Shift to snap by 15 degrees.
  • Edit the frame anchor: Drag the center anchor handle. Double-click to reset.
  • Pan the render box: Hold Shift and drag outside the frames.

Export

  • PNG: Good for flattened layout images.
  • PSD: Keeps render, frame lines, and optional overlays in separate layers.
  • Grid / Eye-level: Optional overlay output.
  • Model layers: PSD-only output for visible GLB models.
  • Reference images: Export only when enabled, visible, and set to include in render.

Reference Images

  • Reference images are managed as presets.
  • You can keep per-camera overrides for visibility, opacity, order, offset, and scale.
  • Reference images can be exported in front of or behind the render.
